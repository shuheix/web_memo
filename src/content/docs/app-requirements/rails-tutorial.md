ユーザー認証つきのミニ SNS（短文投稿＋フォロー）を作るための機能一覧。この一式で MVC・認証・CRUD・関連付け・メール・ファイルアップロード・TDD・デプロイを一通り扱う。

作る順序の目安は 静的ページ → ユーザー認証 → 投稿 → フォロー/フィード。機能の洗い出しは [Rails チュートリアル](https://railstutorial.jp/) を参考にした。

## 機能一覧

### 静的ページ
- Home / Help / About / Contact の表示
- 共通レイアウト（ナビ・フッター）
- ページごとの動的タイトル

### ユーザー管理
- email / password で新規登録
    - バリデーション: 存在性 / 長さ / フォーマット / 一意性
    - パスワードは暗号化して保存
- プロフィール画像
- 登録成功時の flash メッセージ

### ログイン
- 基本
    - ログイン / ログアウト
    - ログイン状態による画面表示の切替
- 発展
    - remember me（ログイン状態の保持）
    - 記憶するかをチェックボックスで選択

### 編集・一覧・削除
- プロフィール編集
- アクセス制御（認可）
    - 未ログインのアクセス制限
    - 本人以外の編集禁止
    - フレンドリーフォワーディング（ログイン後に元のページへ戻る）
- ユーザー一覧（ページネーション）
- 管理者権限
    - 管理者によるユーザー削除

### アカウント有効化
- 有効化メール送信
- メール内リンクからの有効化

### パスワード再設定
- 再設定メール送信
- メール経由の再設定

### 投稿（マイクロポスト）
- 投稿の作成・削除
- 投稿バリデーション
- プロフィールでの投稿一覧
- 画像添付
    - アップロード / 検証 / リサイズ

### フォロー・フィード
- フォロー / フォロー解除
- フォロー中 / フォロワー一覧
- フォロー数などの統計
- フォロー中ユーザーの投稿フィード

## Advance（基本形に足すと新しい技術を扱う機能）

| 追加する機能 | 扱う技術 |
|---|---|
| リアルタイム通知 / DM（チャット） | WebSocket（Action Cable 等）。サーバーからの push |
| 重い処理の非同期化（メール・画像・集計） | 非同期ジョブ（Sidekiq / Solid Queue 等） |
| ソーシャルログイン（Google / GitHub） | OAuth・外部 API 連携 |
| 課金・サブスク | Stripe 連携・Webhook 受信・外部サービスとの状態同期 |
| 全文検索 / 絞り込み検索 | LIKE を超えた検索（pg_search / Meilisearch 等）、インデックス・N+1 |
| role/権限管理の本格化 | 認可ライブラリ（Pundit / CanCanCan 等）、宣言的ポリシー |
| API モード + 別フロント（React/Vue） | JSON API 設計・トークン認証（JWT）・CORS・SPA 分離 |
| 多言語対応（日/英切替） | i18n |
